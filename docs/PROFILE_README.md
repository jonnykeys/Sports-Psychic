### 🏈 Featured Project: [Sports Psychic](https://github.com/jonnykeys/Sports-Psychic)

An NFL score forecasting web app built for my 12-member league to compete each week, complete with live scores, postseason brackets, and cloud persistence.

* **Live Data Ingestion**: Pulls real-time NFL scores, kickoff clocks, and live win probabilities via the ESPN REST API.
* **Custom League Rules**: Implements confidence multipliers, dynamic closest-score bonus pools, and unrounded win-loss tie-breakers.
* **Automated Testing**: 17 modular unit test suites verifying scoring rules and schedule edge cases.
