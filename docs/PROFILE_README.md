### 🚀 Featured Engineering Project: [Sports Psychic](https://github.com/jonnykeys/Sports-Psychic)

An offline-resilient, real-time Progressive Web Application (PWA) for competitive NFL score forecasting, featuring automated sports telemetry and cloud persistence.

* **Deterministic Engine**: Decoupled mathematical scoring engine ([`src/engine/scoring.js`](https://github.com/jonnykeys/Sports-Psychic/blob/main/src/engine/scoring.js)) evaluating prediction differentials, dynamic pool splits, and 3X compounding confidence multipliers with 100% automated test coverage.
* **Temporal State Reconciliation**: Architected a self-healing background audit engine (`catchUpPastWeeks`) that resolved a multi-device distributed state desynchronization bug across NFL schedule rollovers.
* **Security & Lockout Enforcement**: Rolling game lockout policies enforced at client boundary and validated by PostgreSQL Row-Level Security (RLS) triggers.
